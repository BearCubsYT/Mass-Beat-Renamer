# <span style="color:#6a329f">Mass Beat Renamer - A1.0.0

This is an app that will allow for mass beat renaming to match a specific naming scheme. It will also create an MP3 when a WAV file is given!
<br>
<br>

## <span style="color:#6a329f">Example:
<span style="color:#BE75BE">@BearCubs - Neon Glitch - 180BPM - E Major - (Hyperpop · Digicore)</span>
<br><b>Becomes</b> 
<span style="color:#BE75BE"><br>@Bearcubs - 180BPM - E Major - Neon Glitch (Hyperpop, Digicore)

<span style="color:#BE75BE"><b>2. Make sure pip is an available command, if it is not use these to fix </b></span>
<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Windows: <span style="color:#48a0c7">https://www.youtube.com/watch?v=jPRIzVZulhA</span>

<span style="color:#BE75BE"><b>3. Run this command in the terminal of the installation location of this app </b></span>

<span style="color:#BE75BE"><b>4. You can now run the app with no problems like any other normal python program </b>
